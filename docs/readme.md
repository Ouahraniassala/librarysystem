# نظام إدارة مكتبة رقمية مبسط

## الاسم واللقب:
[اصالة وهراني ]

## الفوج:
[03]

## وصف المشروع:
مشروع console بسيط لإدارة مكتبة رقمية باستخدام مفاهيم البرمجة الكائنية.

## مميزات المشروع:
- إضافة واستعارة واسترجاع الكتب.
- إدارة مستعيرين.
- عرض الكتب المستعارة.

## كيف تشغل المشروع:
1. افتح المشروع على Eclipse أو أي محرر Java.
2. شغل الملف `Main.java`.
3. اتبع التعليمات الظاهرة في الشاشة.

## ملاحظات:
- يتم استخدام الوراثة لإنشاء نوعي الكتب.
- كل كود موثق بتعليقات داخلية.
